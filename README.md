# Serpent Sting Hint

WoW Forever 猎人插件。当前目标有你的毒蛇钉刺时显示倒计时。掉毒后，预计还能活超过 10 秒就亮金框。开怪时如果击杀时间尚未算出，目标当前血量达到 5,000 点也会提示。

- **WowUp**：在 WoW Forever 客户端下选择「从 URL 安装」，输入本仓库地址。
- **手动安装**：从 [GitHub Releases](../../releases/latest) 下载附件 `SerpentStingHint-*-forever.zip`，解压到 `_forever_/Interface/AddOns/`。
