# Serpent Sting Hint

供 WoW Forever 1.60.1 的猎人使用。解压 ZIP，将整个 `SerpentStingHint` 文件夹放到 `World of Warcraft/_forever_/Interface/AddOns/`，重新启动游戏。插件独立运行。

| 当前敌对目标的状态 | 图标 |
| --- | --- |
| 有你施放的毒蛇钉刺 | 显示剩余秒数 |
| 没有你的毒蛇钉刺，且估计还能活超过 10 秒 | 金框高亮 |
| 没有你的毒蛇钉刺，开怪时估不出击杀时间，且当前血量至少 5,000 点 | 金框高亮 |
| 没有你的毒蛇钉刺，且以上两个高亮条件均未满足 | 灰色 |

在游戏里打开「选项 → 插件 → Serpent Sting Hint」，或输入 `/sshint`。设置会保存，升级会保留旧版位置。

- **位置和大小**：「解锁并拖动」可以直接移动图标。「锁定位置」结束拖动。缩放范围为 50%–200%，图标和倒计时一起缩放。
- **预览**：脱战可切换倒计时、金框、灰色和关闭。关闭设置面板或进入战斗会结束预览。
- **显隐和提示门槛**：可以隐藏无提示时的灰色图标，调整剩余击杀时间门槛，或关闭及调整开怪血量规则。默认显示灰色图标，门槛为 10 秒和 5,000 点。
- **恢复默认**：面板里的按钮恢复所有设置。`/sshint 140 -100` 可用坐标移动图标，`/sshint reset` 只还原位置。
- **跳过元素生物的补钉刺提示**：默认关闭。开启后，能识别为元素生物的目标不显示补钉刺金框，已施放的钉刺照常显示倒计时。此选项按怪物类别判断，能吃钉刺的元素生物也会跳过。当前目标类别未能识别时，沿用通常的提示规则。

倒计时由客户端按目标身上的实际减益绘制。预计击杀时间来自当前目标掉血速度，单刷和组队都适用。每次切换目标会重新采样，至少观察到 3 次受伤事件、经过 2 秒并有足够的掉血量才会使用击杀时间。5 秒没有新受伤事件就丢弃旧估计。集火变化、转阶段和治疗会影响估算。

开怪血量门槛用的是当前剩余血量。选中敌对目标后，插件在观察到目标进入战斗或首次受伤起的 6 秒内，可以用这条规则填补估算空窗。目标最大血量低于门槛或无法取得时，插件会等击杀时间有足够样本再判断。

设置和交战规则已通过 Lua 模拟验证。游戏内设置布局、不同缩放下的原生减益显示和团本估算仍需实测。
